## Согласованные решения интерфейса
- Телефон: адаптивная шапка в одну строку, логотип/компас, красный телефон с асимметричной анимацией трубки, MAX, поделиться, QR с подписью, три точки. Уважать настройку отключения анимации.
- Сохранить утверждённую мобильную компоновку, крупные читаемые буквы, компактные карточки сравнения с фото слева и текстом справа.
- Ползунки стоимости/аванса/срока: широкая невидимая зона касания, компактный вид; срок 12–84 месяцев, шаг 6; кнопки 24/36/48/60 не возвращать. Не менять формулы без отдельной проверки.
- Контакты и реквизиты сосредоточены в тёмном нижнем блоке; не дублировать.
- ПК от 1024 CSS-пикселей: форма индивидуального расчёта слева под ползунками, результат справа; блок проверки условий рядом с отправкой КП, схема сотрудничества в B2B, увеличенная ширина и сокращённые отступы. Код CSS lk-desktop-layout-v1.
- Новая спецтехника: крупный экскаватор, ряд тракторов, смешанная техника; фотографии выставочных образцов. Проверить фактическую загрузку и лицензии каждого изображения; не выдавать выставочную фотографию за подтверждение наличия новой машины. Б/у — отдельная страница.
- Не менять ссылку, согласованный дизайн мобильной версии или прежние варианты сайта без прямой необходимости.

## Реальное состояние функций
- На сайте присутствуют калькулятор пяти условных сценариев, обмен ссылками/расчётами, партнёрский калькулятор, чек-листы, QR, визитка, PWA-манифест. Наличие манифеста не доказывает установку на всех устройствах.
- Приём заявок и обратных звонков не активирован; не утверждать, что данные отправлены. MAX без подтверждённого рабочего профиля не активировать. В callback номер копируется; Android сам выбирает приложения для tel: ссылок.
- PR #1, feature/seo-engine-v1: подготовка SEO, не слит. Preview noindex,nofollow; robots.txt сам по себе не гарантирует исключения из поиска. Не включать индексацию и не отправлять sitemap/IndexNow до согласованного запуска.
- PR #2, feature/secure-intake-v1: серверный прототип приёма заявок, выключен по умолчанию, тесты на синтетических данных; не развёрнут. Не использовать GitHub Pages как backend и не хранить персональные данные, ключи, токены в Git. Перед запуском — утверждённые правовые материалы, подходящий хостинг, защищённая операторская очередь, HTTPS, защита от спама, сроки хранения/удаления, резервирование.
- Публичный запуск, домен и индексация, магазины приложений, реальные интеграции — отдельные этапы с согласованием. Не менять DNS, настройки ПК и аккаунты самовольно.
- Compass AI, Vision, Link, Smart Matching, CRM, Tender, Legal, Document, Radar, Market, Forecast, Analytics, Voice, Subsidy, Verify, Connect, Intelligence, Evolution, Control, Security — направления развития, не заявлять как уже работающие независимые программы. Приоритет: заявки/CRM, безопасность, проверка и подбор, затем AI.
- Перед каждой правкой читать актуальный main, сделать минимальное изменение, проверить тесты, переходы, размеры мобильного/ПК, статус Pages, сообщить фактический результат. Для изменений в main использовать сравнение ожидаемого SHA. Не обещать фоновых работ и не подменять выполнение планом.
