# Search launch / SEO V4.18

Основной домен: https://leasingcompass.ru/; резервные: lizingkompas.ru, лизингкомпас.рф (301 на основной после подключения). GitHub Pages — демонстрация, не индексировать.

## До запуска
- [ ] DNS и HTTPS основного домена; рабочий хостинг и проверка безопасности.
- [ ] Проверка реквизитов, прав на изображения, цифры 450+, партнёрств, договоров, политики ПД и согласий; при необходимости Роскомнадзор. Не включать реальные формы до готовности.
- [ ] Собрать production-копию: python seo/prepare_release.py --output ../leasingcompass-production --confirm-ready. Скрипт не публикует и не меняет preview.
- [ ] Проверить все страницы, 301 с альтернативных доменов, HTTP/HTTPS и www, root robots.txt и sitemap.xml. Убедиться в отсутствии noindex на публичных страницах и наличии noindex на тестовых/служебных.
- [ ] Проверить Lighthouse мобильный/ПК, Core Web Vitals (LCP, INP, CLS), доступность, битые ссылки, реальные формы и аналитику с соблюдением ПД.
- [ ] Верифицировать домен в Google Search Console https://search.google.com/search-console/ ; Яндекс Вебмастер https://webmaster.yandex.ru/ ; Bing https://www.bing.com/webmasters/ ; отправить sitemap, запросить обход главной и основных услуг.
- [ ] IndexNow: сгенерировать ключ, разместить key.txt в корне production и уведомлять только об изменённых канонических URL после успешного деплоя. Не использовать Google Indexing API для обычных страниц.
- [ ] Проверить доступность для поисковых роботов ИИ, включая OAI-SearchBot, не предоставляя им приватных данных; нет специальных гарантий ранжирования.
- [ ] Настроить аналитику конверсий, контроль ошибок, мониторинг индексации и поисковых запросов. Не создавать массовые одинаковые региональные страницы.

## После запуска
Еженедельно проверять индексацию, sitemap, ошибки, скорость, контент и лиды. Ежемесячно актуализировать справочник, статьи, источники и условия. Продвигать реальные полезные материалы, не выдумывать отзывы, рейтинги или партнёров. Поисковики не гарантируют немедленную индексацию.
